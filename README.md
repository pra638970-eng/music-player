# 🎵 Melodify – Modern Web Music Player

Melodify is a modern and responsive **web-based music player** built using **HTML, CSS, and JavaScript**. It provides a clean dark-themed interface with essential music playback controls and a dynamic playlist.

## ✨ Features

* ▶️ Play / Pause music
* ⏮️ Previous song
* ⏭️ Next song
* 🔊 Adjustable volume control
* 📊 Interactive music progress bar
* ⏱️ Current time and total duration display
* 🔁 Loop / repeat mode
* 📋 Dynamic playlist
* 🎵 Active song highlighting
* 📱 Responsive design for smaller screens
* 🌙 Modern dark glassmorphism-style UI
* 🎧 Multiple songs available in the playlist

## 🛠️ Technologies Used

* **HTML5** – Structure of the music player
* **CSS3** – Styling, responsive design and modern UI
* **JavaScript** – Audio controls, playlist management and player functionality
* **HTML5 Audio API** – Music playback and audio events

## 🎯 Project Highlights

The player dynamically loads songs and updates the song title, artist, progress bar and playlist state. JavaScript is used to control playback, volume, looping, track navigation and playlist interactions.

The project contains a playlist with multiple tracks and uses audio URLs for playback.

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in **VS Code**.
3. Open `index.html`.
4. Run it using **Live Server** or open the HTML file directly in your browser.
5. Click the **Play** button to start listening.

## 🎮 Controls

| Control      | Function                                |
| ------------ | --------------------------------------- |
| ▶️ / ⏸️      | Play or pause the current song          |
| ⏮️           | Play previous song                      |
| ⏭️           | Play next song                          |
| 🔊           | Adjust volume                           |
| 🔁           | Enable/disable loop mode                |
| 📋           | Open/close playlist                     |
| Progress Bar | Seek to a specific position in the song |
